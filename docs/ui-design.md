# LanChat 前端设计规范

## 1. 视觉方向

- 关键词：清爽、现代、聊天工具感；不要"后台管理模板"的土味。
- 主色：Element Plus 默认蓝 `#409EFF`；强调渐变 `linear-gradient(135deg, #667eea 0%, #764ba2 100%)`（登录页背景/品牌区）。
- 中性色：背景 `#f5f7fb`，卡片白色，文字 `#303133` / 次要 `#909399`，分割线 `#e4e7ed`。
- 圆角：卡片 12px，气泡 10px，输入框 8px；阴影轻量 `0 4px 16px rgba(0,0,0,.06)`。
- 字体：系统默认（`system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`），字号 14px 基准。
- 暗色模式：`html.dark` + Element Plus 暗色变量，背景 `#141414`、卡片 `#1d1e1f`。

## 2. 页面结构

### 登录/注册页（`/login`）
- 左右分栏或居中卡片：左侧品牌区（渐变背景 + LanChat logo + 一句 slogan "局域网内的即时沟通"），右侧表单卡片。
- 表单：用户名、密码、（注册）昵称；Element Plus `el-form` 校验；登录/注册切换 tab。
- 页脚：课程信息小字（Java语言及网络编程课程报告项目）。

### 聊天主界面（`/chat`）
```
┌────────────────────────────────────────────────────────────┐
│ 顶栏：LanChat | 在线人数 | 当前用户头像+昵称 | 暗色切换 | 退出 │
├──────────────┬─────────────────────────────────────────────┤
│ 侧栏 (260px) │ 消息区（flex-1）                             │
│ 搜索框       │  日期/系统消息分隔                           │
│ 群聊入口     │  [对方] 气泡（左，白底）                     │
│ 在线用户列表 │  [自己] 气泡（右，蓝色渐变）                 │
│ - 头像/昵称  │  文件卡片（图标/名称/大小/进度/下载按钮）     │
│ - 在线小圆点 │                                             │
│ - 未读红点   ├─────────────────────────────────────────────┤
│              │ 输入区：textarea + 发送按钮（Enter 发送）    │
└──────────────┴─────────────────────────────────────────────┘
```
- 侧栏分两组：「群聊」固定入口；「在线用户」列表（按昵称排序，离线置灰可私聊）。
- 未读消息：侧栏对应用户/群聊显示红点数字；切换会话后清零。
- 消息气泡：自己右侧、别人左侧；显示昵称、时间（HH:mm）；连续同人消息合并间距。
- 系统消息：居中灰字小标签。

## 3. 交互细节

- 登录成功：保存 token/Pinia，建立 WS，跳转 `/chat`，拉取在线列表与群聊历史。
- 发送消息：Enter 发送、Shift+Enter 换行；发送后输入框清空。
- 私聊：点击在线用户进入私聊会话（切换主消息区），拉取 `/api/messages/private/{id}`。
- 文件：点击回形针选择文件 → 上传进度条（`el-progress`）→ 成功后作为文件消息出现在会话中；若在上传时选择了接收人则带 `to`。
- 断线：顶部黄色 `el-alert` "连接断开，正在重连…"；恢复后自动消失并拉取最新消息。
- WS 收到 `message` 时：若属于当前会话则直接追加，否则会话列表红点 +1。
- 错误提示：统一 `ElMessage.error(message)`；401 清 token 回登录页。
