# LanChat 前端设计规范（Editorial Indie 风格）

> 目标：国外独立网站 / 编辑排版（editorial indie）气质——纸张感、克制、细线、大量留白、单一强调色、衬线标题 + 等宽标签。**禁止彩色渐变、禁止 Element 默认蓝、禁止大阴影与大圆角。**

## 1. 设计原则

1. 以内容与排版为主角，界面退到边界之后：细线分隔、留白、小字号元信息。
2. 单色体系 + 一个暖橙强调色；绿色只用于在线状态圆点。
3. 衬线用于品牌与标题，等宽用于标签/数字/时间，正文用系统无衬线。
4. 形状克制：圆角 2–6px，阴影几乎不用，交互反馈靠细线、下划线、字重与底色反转。

## 2. 设计令牌

### 浅色

| 变量 | 值 | 用途 |

| `--ink` | `#1a1a17` | 主文字 / 自方气泡底 / 按钮底 |
| `--ink-soft` | `#2b2a25` | 悬浮/次强调 |

| `--online` | `#2f7d4f` | 在线圆点（仅此用途） |

### 字体

- 品牌/标题：`Iowan Old Style, Palatino Linotype, Palatino, Georgia, "Noto Serif CJK SC", serif`
- 正文：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`，14px / 1.6
- 元信息、标签、时间、数字：`ui-monospace, "SFMono-Regular", Menlo, Consolas, "Noto Sans Mono CJK SC", monospace`，10–11px，字距 0.08–0.14em，大写英文

### 形状

- 圆角：输入框 3px、按钮 3px、气泡 4px、文件卡片 4px、登录面板 6px、头像 4px（方形小圆角）。
- 阴影：不使用（悬浮可用 `--line-strong` 边框或 1px 位移反馈）。
- 分隔：统一 1px `--line`；重要区块之间可用 1px `--ink` 或更大留白。

## 3. 页面结构

### 登录 / 注册页（`/login`）

- 左右分栏（窄屏上下堆叠）：
  - 左侧纸色区：大号衬线 "LanChat" 字标；其下一行等宽小字 `LOCAL NETWORK MESSENGER`；细线；三到四条等宽能力说明（`JAVA 21 · SPRING BOOT 3.5` / `VUE 3 · ELEMENT PLUS` / `SQLITE · WEBSOCKET`）；底部等宽状态行：绿色小圆点 + `OPERATIONAL · :8081`。
  - 右侧白色表单面板：左侧 1px 细线；标题衬线 "Welcome back / 欢迎回来"，副标题等宽小字；登录/注册 tab 为下划线文字样式（激活为墨色 2px 下划线）；输入框细线边框、聚焦时 `--line-strong`；提交按钮墨底纸色文字、等宽大写加字距（`LOG IN · 登 录`）；底部等宽小字版权与项目行。
- 页脚：等宽 `LanChat · Java语言及网络编程课程报告项目 · 2026`。

### 聊天主界面（`/chat`）

```
┌──────────────────────────────────────────────────────────────────┐
│ LanChat（衬线） · ONLINE 2（等宽）        [LIGHT/DARK] [退出]      │  56px，细线底边
├────────────────┬─────────────────────────────────────────────────┤
│ 搜索（细线）    │  群聊（衬线） · 2 人在线（等宽）                  │
│ GROUP CHAT（等宽小标题）                                          │
│  ○ 群聊（激活：左2px墨条+白底+细框）                              │
│ PEOPLE（等宽小标题）                                              │
│  ○ 鲍勃  在线小绿点   · 未读红点                                  │
├────────────────┴─────────────────────────────────────────────────┤
│  时间/系统消息（居中等宽小字）                                     │
│  [对方] 白底细框气泡        [自己] 墨底纸色字气泡（右）            │
│  [文件卡片] 白底细框 + 等宽元信息 + 下划线下载                     │
├──────────────────────────────────────────────────────────────────┤
│  工具栏（等宽小字：发送至 / 字数）                                 │
│  [输入框：白底细线]                        [SEND ⏎ / 发送 墨底按钮] │
└──────────────────────────────────────────────────────────────────┘
```

- 侧栏 260px，纸色底，右侧 1px 细线；分区标题等宽大写 11px 字距；会话项无胶囊（激活 = 左侧 2px `--accent` 或墨色竖条 + `--surface` 底 + 1px 细框）；头像 26–28px 方形小圆角，等宽首字母；在线 6px 绿点；未读数等宽小字。
- 消息区纸色底；气泡最大宽度 70%；对方气泡 `--surface` + 1px `--line`，自己气泡 `--ink` 底 + `--paper-on-ink` 字；时间/昵称等宽 10–11px `--muted`；系统消息居中等宽小字。
- 输入区：`--surface` 底、1px `--line`，工具栏等宽小字；发送按钮墨底（禁用时 `--muted` 文字 + 细线）。
- 断线提示：顶部 1px 细线的纸色条 + 等宽小字与强调色小点，不使用彩色大色块。

## 4. 交互细节

- 交互反馈：下划线（链接/下载）、边框加深（悬浮）、底色反转（按钮）、字重变化（标签）；一律无阴影、无渐变。
- 主题切换：顶栏等宽文字按钮 `LIGHT` / `DARK`，切换 `html.dark` 并持久化 `localStorage`。
- 加载/空状态：等宽小字 + 细线框，不使用彩色插图。
- 文件：进度用细线进度条（`--ink` 填充、`--line` 轨道），元信息等宽小字（大小 / SHA-256 校验），下载为下划线文字。
- 断线重连：顶部细线提示条 + 等宽文字（`RECONNECTING · 3s`）。

## 5. 验收清单

1. `grep -R "gradient" frontend/src` 无结果。
2. 登录/注册、聊天、私聊、文件、暗色五类界面截图（1440×900）符合本文规范。
3. 深浅两套令牌下文字对比度足够（正文对背景 ≥ 7:1，次要文字 ≥ 4.5:1）。
4. 390px 窄屏：登录面板堆叠、侧栏可收起/抽屉、消息气泡不溢出。
5. 现有功能与选择器契约不变（E2E 依赖 `.login-page`、`.chat-view`、`.status-dot.connected`、`.conversation-item.user-item`、`.message-textarea textarea`、`.send-button`、`.theme-switch`、`.submit-button`）。
